Notes & observations
--------------------

- firstTrue/lastTrue/countTrues implement common reductions over boolean vectors using @select and @reduce — used by indexOfSentinel via std.simd.firstTrue.
- Many tests in this file validate correctness and document architecture limitations (some functions skip tests on MIPS or specific backend/arch combos).
